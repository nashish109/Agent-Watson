# @agent-watson/ui

React UI component library — Agent Watson's design system.

## Principles

- Accessible (WCAG AA compliant)
- Themeable (light/dark mode)
- Composable (small primitives, composed into complex UIs)
- Server-component compatible (Next.js RSC)

## Component Categories

- **Primitives:** Button, Input, Select, Card, Badge, Tooltip
- **Layout:** Stack, Grid, Sidebar, Shell
- **Domain:** KnowledgeGraph, Timeline, Dashboard, ProgressChart
