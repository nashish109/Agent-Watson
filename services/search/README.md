# Search Service

Hybrid search engine for Agent Watson.

Combines PostgreSQL full-text search (FTS) with vector similarity search (pgvector)
to provide fast, relevant results across all knowledge domains.

## Features (planned)

- Full-text search with relevance ranking
- Semantic search via embeddings
- Hybrid search (weighted FTS + vector)
- Faceted filtering (by type, date, tags, project)
- Typo-tolerant query suggestions
